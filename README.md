# MiSTer Wipeout Project
This project aims to bring Submarine (AY-3-8605) and Wipeout (AY-3-8606) Pong-On-A-Chip chipset simulation into the MiSTerFPGA world; Just like the PONG (AY-3-8500) chipset simulation that was brought over by Cole Johnson a few years ago.
All of the hard work, ranging from Scanning the chips (By Sean Riddle: https://seanriddledecap.blogspot.com/), Providing the chipset information (By David Winter: http://www.pong-story.com/), Making the files and the JS simulators (By Cole Johnson: https://nerdstuffbycole.blogspot.com/ and Visual6502 Team: https://github.com/trebonian/visual6502) and everything else belong to the mentioned creators; All i did was to revive the lost links and files to continue the project of porting these chips into MiSTerFPGA. As quoted by Cole himself: "While you are not legally required to, it would be appreciated that, if you reproduce or develop this work, you;

	-Provide links to the original creators (Cole Johnson and the Visual6502 team) beyond those in the source
	-Notify me of any projects/uses the simulator has helped you with
	-Publish the source of any new versions so others can learn from and expand upon our work"

  So that's what i'm doing here. in the README.txt file, i have explained the file structure and what i have or not. As a newbie in this field, I'm not sure if what i've collected is sufficient for porting these chips into MiSTerFPGA; But some of you might have enough knowledge for or be interested in contributing to this project.
